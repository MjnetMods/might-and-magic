# Lava-Filled Apothecary as Light Source

An Apothecary filled with lava should emit light like a normal lava source block, rather than staying dark.

**Why:** currently the only fluid-related rendering `design/magic/10_apothecary.md` documents is fill-height and sprite/tint (per that doc's Open Questions) — no light-level behavior. A lava-filled Apothecary reading as visually dark breaks the fluid's own affordance.
