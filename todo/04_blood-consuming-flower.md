# Blood-Consuming Flower (→ NOX)

A generating flower that consumes Blood fluid from an Apothecary and generates NOX directly, the way existing Verdant flowers consume an ingredient/condition and generate Mana.

**Why:** `design/magic/10_apothecary.md`'s Nox-bootstrap path (Apothecary + Blood/Lava → Mana Spreader → taints a pool) is currently a passive drain, not a flower entity. A dedicated flower would give Sanguine its own active, on-theme NOX generator, parallel to how Verdant's generating flowers each key off a specific trigger.

**Q:** Does this flower sit in the Sanguine school's block set, or is it a Verdant-style generating flower reskinned for Sanguine? Depends on how `design/40_sanguine-path.md` ends up handling block/plant ownership for its pillars.
